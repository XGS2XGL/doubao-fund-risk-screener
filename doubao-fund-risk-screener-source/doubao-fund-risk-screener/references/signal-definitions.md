# 四大信号维度定义与阈值

本文件是 compute_signals.py 与归因分析的口径依据。所有比例分母用「总资产」或对应基数；数值统一为亿元。任何阈值调整都在输出中注明档位。

## 输入 CSV 列名约定

compute_signals.py 读取的财务数据 CSV 列名（同时接受中文列名），单位均为亿元：

| 列名（英文） | 中文 | 说明 | 必填 |
|---|---|---|---|
| code | 证券代码 | 如 600519 | 是 |
| name | 证券简称 | 如 贵州茅台 | 是 |
| industry | 所属行业 | 可选 | 否 |
| report_date | 财报截止日期 | YYYYMMDD 或 YYYY-MM-DD | 是 |
| report_type | 报告类型 | 如 2024年年报 | 否 |
| monetary_funds | 货币资金 | | 是 |
| short_loan | 短期借款 | | 是 |
| long_loan | 长期借款 | | 是 |
| bonds_payable | 应付债券 | | 是 |
| noncurrent_1y | 一年内到期的非流动负债 | | 是 |
| finance_expense | 财务费用 | 可为负（净利息收入） | 是 |
| accounts_receivable | 应收账款 | | 是 |
| inventory | 存货 | | 是 |
| net_profit | 净利润 | | 是 |
| op_cashflow | 经营活动现金流净额 | | 是 |

| hard_evidence | 实锤标记 | 0/1；公告/审计/监管实锤后由归因阶段补入 | 否 |

## 通用口径

- **有息负债 = 短期借款 + 长期借款 + 应付债券 + 一年内到期的非流动负债**（如另有租赁负债等可并入并在输出注明）。
- **同比**：用目标年度与上一年度年报同口径比较；连续两年指目标年及前一年。
- **数据缺失**：某科目缺失则跳过依赖它的子指标，该维度按已有子指标计分，并在输出 coverage 列标注"部分信号"；全缺记 0 并标"数据缺失"。

## 维度 1 存贷双高（满分 25）

核心逻辑：账面货币资金充裕却同时承担高额有息负债。经典案例：康美药业、康得新——常见真实货币资金不足，或货币资金被质押/占用。**注意：银行/非银金融行业存贷结构天然特殊，默认排除金融行业或单独口径。**

子指标（a/b/c 同时成立才判"存贷双高信号"）：

- a. `货币资金 / 总资产`：默认 ≥20%（严格 15%，宽松 25%）
- b. `有息负债 / 总资产`：默认 ≥20%（严格 15%，宽松 25%）
- c. `有息负债 / 货币资金`：默认 ≥50%（严格 40%，宽松 60%）
- d. 交叉检验——**利息收益率** `利息收入 / 货币资金`（利息收入缺失时用 `max(0, -财务费用)` 近似）：明显低于同期存款基准利率（默认 <1.5%，严格 <1%，宽松 <2%）→ 货币资金真实性存疑，高危标记。示例：账面 150 亿货币资金但年利息收入不足 1 亿（康得新特征）。

计分：得分 = 触发子指标数 × 8 + (d 触发 +5)，封顶 25。a/b/c 未同时满足但 d 触发，仍 +5 并标"货币资金真实性存疑"。

## 维度 2 现金流与利润背离（满分 25）

- a. `经营活动现金流净额 / 净利润`：默认 <0.5（严格 <0.3，宽松 <0.7），且**连续两年**成立 → 强信号（12 分）。
- b. 净利润为正但经营现金流净额为负，**连续两年** → 高危（13 分）。
- c. 近三年累计 `经营现金流净额 / 累计净利润` <0.5（需三年数据）→ 8 分。
- 计分：a(12) + b(13) + c(8)，封顶 25；b 触发即 ≥13 分。
- **归因注意**：高成长、预收款模式（部分消费/地产/工程类）现金流天然偏低，归因时结合行业解释，不直接定罪。

## 维度 3 资金占用 / 违规担保（满分 25）

**表内信号**（财务数据可算）：

- a. `其他应收款 / 总资产` ≥5%（严格 3%，宽松 8%）且同比增速 >50% → 8 分。
- b. 其他应收款同比增速连续两年 >100% → 8 分。
- c. 货币资金高（/总资产>20%）且其他应收款同高（/总资产>5%）→ 大股东占用常见路径，4 分。
- 其他应收款字段缺失时该维度仅按公告实锤计分。

**公告/监管信号**（Step 5 用 doubao-announcement-analysis + general_search 核验，命中即 `hard_evidence=1`，该维度直接 25 分并标"实锤"）：

- 资金占用公告（含非经营性资金往来异常、控股股东及关联方资金占用）
- 违规担保公告
- 问询函/监管函涉及资金往来、货币资金真实性
- 非标审计意见（保留意见/无法表示意见/带强调事项段），尤其涉及货币资金与往来款
- 立案调查（资金相关）

## 维度 4 应收 / 存货 / 财务费用异常（满分 25）

- a. `应收账款同比增速 - 营业收入同比增速` ≥50 个百分点（严格 30pp，宽松 80pp）→ 7 分。分母为负的增速按异常处理（营收下滑而应收大增即触发）。
- b. `(应收账款+应收票据*) / 总资产` >15%（严格 10%，宽松 20%）且占比同比上升 → 7 分（无应收票据数据时单用应收账款，口径注明）。
- c. `存货同比增速` ≥50%（严格 30%，宽松 80%）且 `存货 / 总资产` >20% → 6 分。
- d. 财务费用异常（5 分）：
  - d1. 财务费用 >0 且 `财务费用 / 有息负债` <2%（严格 1%，宽松 4%）→ 利息支出与负债规模不匹配，提示表外负债或货币资金虚增；
  - d2. 货币资金 / 总资产 >20% 但财务费用仍为净支出（>0）→ 利息收入未能覆盖，与维度 1d 呼应。
- **高危提示**（不计分但标记）：营收平稳而应收与存货同时大增（勾稽矛盾）。

## 风险分级与综合评分

- 综合评分 = 四维得分之和（0~100）。
- 风险等级（默认档）：≥70 高；40~69 中；<40 低。
- 严格档：≥60 高；30~59 中。宽松档：≥80 高；50~79 中。
- `hard_evidence=1`（任一维度实锤）→ 直接升为"高"，并在输出标注实锤类型。
- 金融行业（银行、券商、保险、多元金融）默认排除，或按独立口径处理并在报告中说明。
