# A股资金管理风险筛查

对上市公司年报数据做四维度信号筛查，找出资金管理问题明显的公司，供论文选题、案例研究或风险初筛使用。筛查的是"资金管理问题"（财务异常信号），不等同于认定舞弊；结论必须区分"已证实问题"与"疑似信号"。

## 执行总览

1. 确认参数（报告年份、范围、阈值档位、输出形式）
2. 构建股票池（全A股或指定范围）
3. 批量获取年报财务科目（seed_finance_lookup 主通道）
4. 运行 scripts/compute_signals.py 计算四维信号与综合评分
5. 大模型深度归因 + 公告/新闻核验
6. 输出风险清单、深度报告、论文选题素材

## 数据通道（重要约束）

- **财务科目主通道**：`seed_finance_lookup`（豆包官方合作金融数据库）。已实测可返回：货币资金、短期借款、长期借款、应付债券、一年内到期的非流动负债、财务费用、应收账款、存货、净利润、归母净利润、经营活动现金流净额、资产合计（总资产）、营业收入、股东权益合计、报告类型（年报/中报/季报）。查询词模式：`{代码} {简称} {年份}年年报 货币资金 短期借款 长期借款 应付债券 一年内到期的非流动负债 财务费用 应收账款 存货 净利润 经营活动现金流净额 总资产 营业收入`。
- **股票池**：用 `seed_finance_lookup` 查询"全A股列表/沪深京全部上市公司"类关键词，取证券代码、证券简称、所属行业、总市值；或按行业/指数成分逐批获取。
- **公告核验**（资金占用/违规担保、问询函、审计意见、监管处罚）：读取并使用 `doubao-announcement-analysis` Skill 检索解读公告；辅以 `general_search` 检索新闻与监管信息交叉验证。
- **禁止**：东方财富 push2.eastmoney.com 等数据 API 已被 robots.txt 拦截，`web_fetch` 不可用，不要尝试绕过、不要编写针对东财的 Python 爬虫脚本。数据一律走上述工具通道。
- **可视化**：风险分布、信号对比等图表按 `doubao-visualization` Skill 产出（ECharts/HTML），不在纯文本里用 ASCII 图代替。

## Step 1 参数确认

与用户确认以下参数（用户不指定即用默认值，并在报告中注明）：
- **报告年份**：默认最近一个完整年报年度（当前年度的上一年）。
- **范围**：默认全A股；可选指定行业/指数成分/自选股票池（用户提供清单或名称）。
- **阈值档位**：默认 / 严格 / 宽松，见 references/signal-definitions.md。
- **输出形式**：风险清单（CSV/Excel）+ 深度报告（飞书文档）+ 论文选题素材（默认）；或用户指定其中部分。

## Step 2 构建股票池

1. 用 `seed_finance_lookup` 获取全A股列表（代码、简称、行业、总市值），落盘为 `universe.csv`。
2. 按用户范围过滤（行业/指数成分/自选）。
3. 记录公司总数。全A股约 5000+ 家：按行业或每 300~500 家一组分片，逐片走"获取→计算"，片间相互独立、可并行；规模大时用 OrganizeAgent 分片并行，每片独立完成获取与初步计算后再合并。

## Step 3 批量获取年报财务科目

1. 每家公司查询目标年度年报**及上一年度年报**（同比用），一次查询尽量带全字段（见数据通道查询词模式）。
2. 字段缺失时，用更细关键词补查一次（如单独查"其他应收款""利息收入"）。
3. 逐条记录到财务原始数据 CSV，列名见 references/signal-definitions.md「输入 CSV 列名约定」。**单位统一换算为亿元**：工具返回的 `1,897.42万` 记 0.19、`543.43亿` 记 543.43、纯数字原始元值（如 59295822956.89）除以 1e8。
4. 用「财报数据截止日期 + 报告类型=YYYY年年报」定位目标年度，勿混入中报/季报。
5. 明显异常值（如货币资金为负）标记待核验，不静默丢弃。

## Step 4 信号计算

```bash
python3 scripts/compute_signals.py <财务数据.csv> <输出路径.csv> --year <报告年份> [--tier default|strict|loose]
```

脚本按 references/signal-definitions.md 口径计算，输出每家公司：四维信号明细值、维度得分（各 0~25）、综合评分（0~100）、风险等级（高/中/低）、触发信号清单、数据覆盖标记。脚本只算财务表内信号；公告/监管实锤信号由 Step 5 补入。

## Step 5 深度归因（大模型分析）

对综合评分靠前（默认取风险等级"高"，或评分 Top 20，数量用户可调）的公司逐家归因：

1. **财务画像**：货币资金 vs 有息负债、现金流 vs 净利润、应收/存货/财务费用近三年趋势。
2. **公告核验**：用 `doubao-announcement-analysis` 检索该公司公告——资金占用、违规担保、问询函回复、非标审计意见、立案调查、商誉减值等。
3. **新闻交叉验证**：用 `general_search` 检索新闻与监管处罚。
4. **结论定性**：每家输出"问题定性 + 证据链 + 严重程度"，明确区分：
   - **已证实问题**（公告/审计/监管实锤，标注证据来源）；
   - **疑似信号**（仅指标异常，无实锤，标注待验证）。

## Step 6 输出

1. **风险清单**：CSV/Excel。按风险等级（高→低）、综合评分（降序）排列，含四维信号值与问题标签、证据类型列。
2. **深度报告**：飞书文档。含方法说明（年份、范围、阈值档位、数据来源与局限）、风险分布可视化、Top 公司案例分析（含证据链）、完整清单附录。
3. **论文选题素材**（用户在做论文选题时默认输出）：
   - 候选论文题目（如"存贷双高识别与财务舞弊预警——基于 A 股年报的实证研究"）；
   - 可研究案例库（3~5 家典型公司，标注信号类型与实锤证据）；
   - 变量与指标设计建议（四维度对应的可操作变量与数据来源）；
   - 数据来源与局限性说明。

## 质量检查

- 每个关键数字标注来源（公司 + 报告期），区分"已查证"与"一方称"。
- 阈值判定可复算：数值与档位口径在 references/signal-definitions.md 有明确约定。
- 深度归因必须有公告/新闻/审计证据支撑，指标异常不等于舞弊。
- 交付前用 verifier-hub / artifact-preview 校验清单与报告产物。
